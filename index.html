Introducción

Esto es una práctica de la asignatura Entornos de desarrollo del Ciclo Superior de Desarrollo Web.

Que es Git

Git es un sistema de control de versiones distribuido. En términos sencillos, es una herramienta que utilizan los desarrolladores para registrar y rastrear todos los cambios que hacen en el código fuente de un proyecto a lo largo del tiempo.

Conflictos al trabajar con ramas

Conoce Git Hub

GitHub es una plataforma basada en la nube que sirve para alojar, gestionar y trabajar en proyectos de código utilizando Git.

Trabajo con ramas

El trabajo con ramas en Git es el proceso diario mediante el cual los desarrolladores crean entornos de trabajo aislados para desarrollar nuevas funciones, corregir errores o experimentar sin alterar la versión estable del proyecto (main).
